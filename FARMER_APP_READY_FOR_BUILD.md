## 🔌 API Endpoints Used

All endpoints connect to: `https://api.zammunda.com`

1. **POST** `/api/farmers/login`
   - Body: `{ phone, pin }`
   - Returns: `{ token, farmer }`

2. **GET** `/api/farmers/me`
   - Headers: `Authorization: Bearer <token>`
   - Returns: Farmer profile data

3. **PUT** `/api/farmers/me`
   - Body: Profile updates
   - Returns: Updated farmer data

4. **GET** `/api/farmers/me/receipts`
   - Returns: Array of warehouse receipts with loans

5. **GET** `/api/farmers/market`
   - Query: `?district=<farmerDistrict>`
   - Returns: Market prices for farmer's district

6. **POST** `/api/farmers/advisor` (Future)
   - Body: `{ question }`
   - Returns: AI advisor response

## 🚀 What Happens When You Build

### npm install
- Downloads 234 packages (~150 MB)
- Installs Capacitor and dependencies
- Takes: 2-3 minutes

### npx cap sync android
- Creates Android project structure
- Copies www/ files to Android assets
- Configures Capacitor plugins
- Takes: 30 seconds

### Android Studio Build
- Gradle downloads build tools
- Compiles Java/Kotlin code
- Packages web assets
- Creates APK file
- Takes: 3-5 minutes (first time)

### Output
- **File**: `android/app/build/outputs/apk/debug/app-debug.apk`
- **Size**: ~8-9 MB
- **Type**: Debug build (for testing)
