STEP 2: PULL LATEST CODE
-------------------------
Once connected, run these commands:

    cd /home/peter/dzalasmart

STEP 3: INSTALL DEPENDENCIES
-----------------------------
    cd server
    npm install


STEP 4: RESTART THE API
------------------------
    pm2 restart nzeru-api

Or if not running yet:

    pm2 start src/index.js --name nzeru-api


STEP 5: VERIFY DEPLOYMENT
--------------------------
Check the logs:

    pm2 logs nzeru-api --lines 20


STEP 6: TEST THE API
--------------------
From your local machine or browser, test:

    https://api.zammunda.com/health
    https://api.zammunda.com/api/mobile/stats
