================================
PRE-BUILD CHECKLIST
================================

Before building the APK, make sure you have:

☐ Android Studio installed
  → Download from: https://developer.android.com/studio
  
☐ Node.js v22+ installed
  → Check: Open CMD and run: node --version
  → Should show: v22.x.x or higher
  
☐ JDK 17+ installed (comes with Android Studio)
  → Check: Open CMD and run: java --version
  
☐ Android SDK installed (comes with Android Studio)
  → In Android Studio: Tools > SDK Manager
  → Make sure these are checked:
     • Android SDK Platform 33
     • Android SDK Build-Tools 33.0.0
     • Android SDK Platform-Tools

☐ Gradle (comes with Android Studio)
  → No manual installation needed

☐ Internet connection
  → First build needs to download dependencies (~200MB)
