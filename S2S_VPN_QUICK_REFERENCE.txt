🎯 WHAT IS S2S VPN?
═══════════════════════════════════════════════════════════════════════════

Site-to-Site VPN = Permanent encrypted tunnel between two networks

    NOT a user-based VPN (like VPN apps on phones)
    ✓ Always-on tunnel between Airtel's network and your VPS
    ✓ Transparent to applications (USSD app doesn't need changes)
    ✓ All traffic automatically encrypted and routed through tunnel

⚙️ WHAT YOU WILL DO (After receiving Airtel's config)
═══════════════════════════════════════════════════════════════════════════

Step 1: Install VPN Software
────────────────────────────────────────────────────────────────────────────
$ sudo apt install strongswan strongswan-pki -y

Step 2: Configure VPN
────────────────────────────────────────────────────────────────────────────
Edit: /etc/ipsec.conf (with Airtel's settings)
Edit: /etc/ipsec.secrets (with Airtel's PSK)

Step 3: Enable IP Forwarding
────────────────────────────────────────────────────────────────────────────
$ sudo sysctl -w net.ipv4.ip_forward=1

Step 4: Configure Firewall
────────────────────────────────────────────────────────────────────────────
$ sudo ufw allow 500/udp    # IKE
$ sudo ufw allow 4500/udp   # NAT-T

Step 5: Start VPN
────────────────────────────────────────────────────────────────────────────
$ sudo ipsec restart
$ sudo ipsec up airtel-ussd-s2s

Step 6: Test VPN
────────────────────────────────────────────────────────────────────────────
$ sudo ipsec status         # Check tunnel is up
$ ping 172.26.166.100       # Ping Airtel's gateway

Step 7: Update USSD App
────────────────────────────────────────────────────────────────────────────
Update IP whitelist in server/src/app.js to allow 172.26.0.0/16

Step 8: Test USSD
────────────────────────────────────────────────────────────────────────────
Ask Airtel to send test USSD request through VPN
